# MyUi-A 完整首页设计规范

## 版式与排版

- 内容最大宽度 `72rem / 1152px`，左右 `24px` 安全内边距。导航初始外容器最大 `80rem / 1280px`。
- 字体声明实测为 `Public Sans, sans-serif`，等宽代码为系统 `ui-monospace` 栈。未观测到字体文件成功加载，不能把声明当成字体下载成功；复用时采用可靠的中文系统回退。
- 原站断点：sm `640px`、md `768px`、lg `1024px`。这是 CSS 视口宽度，不是截图图片的物理像素。
- 主标题：`clamp(2.25rem,4.5vw,3.25rem)`，700，行高 1.15，字距 -0.025em；一行主陈述与下一行渐变关键短语。
- 区块标题：手机 24px，桌面 30px，700，行高 1.25；结尾标题桌面 36px。卡片标题 14px/600；流程标题 16px/600。
- 描述：首屏手机 16px、桌面 15px，行高 1.625；普通段落 14px；辅助说明 12px。区块 eyebrow（小标题）为 12px、宽字距、弱灰。
- 正文区块上下 96px，md 起 128px。首屏上方 96 / 128 / 144px，下方 64 / 96 / 112px，分别对应基本 / md / lg。

## 从上到下的全部主要元素

### 1. 品牌与固定导航

| 元素 | 基准与状态 |
|---|---|
| 品牌标记 | 28px 方形、8px 圆角；悬停 scale(1.05)；字标约 16px 高；目标产品使用自己的标记 |
| 桌面导航 | 五个文本入口；14px/500，水平小间隙；当前页／悬停提高前景色 |
| 导航工具 | 语言、主题、通知图标约 19px，点击区域约 36px；组间 1px 弱分隔线 |
| 登录 | 32px 高，小尺寸蓝色按钮；业务项目接实际登录／用户菜单 |
| 顶部状态 | 固定 z=50，64px 高，透明背景，外容器最大 1280px |
| 滚动状态 | `scrollY > 20px` 收拢；容器最大 832px，顶部 12px；栏高 48px，圆角 16px，底色 60%，背景模糊 40px |
| 变形动效 | 700ms，`cubic-bezier(.16,1,.3,1)`；位置、宽度、圆角、表面同步变化 |
| 语言菜单 | 原站：简体中文、English、Français、Русский、日本語、Tiếng Việt、繁體中文；弹层圆角、小阴影、当前项状态 |
| 主题菜单 | 浅色、深色、系统三项；太阳／月亮图标旋转缩放切换。主题设置可持久化 |
| 通知浮层 | 锚定通知按钮下方，宽 `min(416px,100vw - 16px)`、内边距 12px；标题＋副说明＋通知／时间线双标签＋可滚动正文＋关闭按钮 |
| 通知状态 | 可有红色未读数字；时间线带节点、相对时间与日期。实际公告正文不属于可复用设计数据 |
| 手机导航 | `<640px` 收起桌面链接和语言／公告工具；保留品牌、主题和汉堡按钮。展开为近全屏暗色／浅色遮罩面板，链接纵向错峰出现，底部登录；汉堡变 X，锁定背景滚动 |

原站在需要登录的业务链接上还可能弹出登录引导。这属于目标产品业务逻辑，不要求样式复用时复制倒计时或登录限制。

### 2. 首屏背景、文案与行动

背景准确配方见 [background-and-color.md](background-and-color.md)。

桌面使用 12 列栅格，左右各占 6 列、列间距 32px、顶端对齐；`<1024px` 单列，间距 48px，演示面板再加 32px 顶距。左侧维持左对齐，不在手机端改成整体居中。

1. 状态胶囊：11px/500，圆角 fully rounded（全圆角），蓝色 5% 背景、20% 边框，左右 12px／上下 6px；左边 6px 蓝点与扩散脉冲。
2. 主标题：胶囊下方间隔 20px，主陈述＋换行后的渐变短语。
3. 说明段：标题下方 20px，最大 576px，次级文字的 80% 透明度。
4. 三个行动入口：说明下方 32px，水平间隔 12px，可换行；首屏按钮高 44px、左右 20px，主入口蓝实底带右箭头，次入口描边，第三个描边带打开书本图标。参考站按钮实际通用圆角会受到组件基础样式影响；模板用约 12px 统一实现。
5. 主按钮 hover 箭头向右约 2px，200ms；按钮按下 scale(.98)，禁用态约 50% 不透明度。

### 3. 应用支持带

位于按钮下方 40px。10px 粗体宽字距小标签＋12px 一行说明，下面隔 16px 放应用胶囊。

- 原站两个实际外链应用和一个“更多”展示胶囊；“更多”在本次观察中不是可点击按钮，不能声称已验证弹出应用列表。
- 胶囊：1px 弱边框、muted 15% 背景、全圆角、左右 20px／上下 10px、14px/500；图标约 24px；间距 12px；hover 轻微 scale(1.02)、300ms。
- 图标加载失败有字母占位。迁移后使用目标产品的真实合作方；无合作资料时改成协议、工具类型或明确示例，不伪造合作关系。

### 4. 四协议 API 演示面板

外部最大宽度 672px，圆角 16px、细边框、冷蓝黑／白色 95% 半透明表面与柔阴影。

| 层次 | 细节 |
|---|---|
| 顶栏 | Chat、Responses、Claude、Gemini 四标签，11–12px；激活项 2px 下划线。右侧 6px 绿点带 8px 弱辉光＋10px 等宽 `200 OK` |
| 接口条 | 左侧 POST 颜色胶囊，10px 等宽粗体；路径 12.5px；左右 20px／上下 12px；路径过长截断并可提供完整 title |
| 请求／响应 | 总高度 **400px**，两行 `235px minmax(0,1fr)`；各左右 20px／上下 16px。12.5px 等宽，行高 1.55；保留缩进，允许长行折行 |
| 区域标签 | REQUEST／RESPONSE，10px/600，大写，字距 .18em，弱灰；响应区有极淡表面与上边线 |
| 指标栏 | latency（延迟）／tokens（词元）／cost（成本），10px、等宽等宽数字；右侧 `STREAM · SSE`；细点分隔 |
| 轮播 | 每 **4500ms** 进入一次淡出，**220ms** 后换内容，淡入淡出 200ms；手动切换清除自动轮播，避免用户阅读时跳动 |

原站的公开演示内容如下，仅用于视觉基准，不能视为测得的服务性能或模型价格：

| 标签 | 路径 | 强调色 | 示例延迟／词元／成本 |
|---|---|---|---|
| Chat | `/v1/chat/completions` | 绿 | 142ms / 27 / $0.00081 |
| Responses | `/v1/responses` | 琥珀 | 168ms / 31 / $0.00093 |
| Claude | `/v1/messages` | 蓝 | 156ms / 29 / $0.00087 |
| Gemini | `/v1beta/models/{model}:generateContent` | 紫 | 93ms / 25 / $0.00075 |

`starter.js` 将这些作为明确标记的本地演示数据，不访问原站服务。辅助技术使用 tablist/tab/tabpanel（标签组／标签／面板）语义，支持方向键与 Home/End；自动轮播不应反复播报到屏幕阅读器。

模板的请求区上下内边距微调为12px／8px、标签行高12px、标签下距6px，以在保持235px固定分区的前提下放下十行示例。手机长行仍可在区块内滚动，滚动条采用低对比细线；这是排版适配，原站采集值仍如上表所列。

### 5. 四项数字带

首屏之后的全宽细边线区：border 上下 40% 强度，背景 muted 10%。内容区上下 40px，md 起 48px；手机 2×2，桌面 4 列，间距 32 / 48px。数字 24 / 30px、700、tabular-nums（等宽数字），说明 12px、上隔 6px。

原站最终示例计数为 50+／100+／50+／10+；观察过程中出现的 0+ 和中间数字是入场动画，不能固化为最终统计。动画可视阈值 .5、1600ms、easeOutCubic（立方缓出），只触发一次。目标产品使用自己的事实，或像模板一样展示可验证的模板配置数量。

### 6. 主功能拼接卡：四张、三列、两行

区块标题左对齐，后隔 64px。外框 12px 圆角、overflow hidden（裁剪溢出）、细边框；网格间距 1px，用底层边框色形成连贯分隔。md 以上 3 列，依次跨 2 / 1 / 1 / 2 列；手机全部单列。卡内边距 28px，md 起 32px。hover 只轻微增亮表面，300ms。

每张卡标题行均为：28px 的数字角标（01–04）、12px 间隙、14px/600 标题。角标为 10px 等宽数字、小圆角、muted 表面与弱描边。下方 14px 说明，再隔 16px 放功能可视元素：

- **01 极速／广泛支持**：2 行×3 列厂商或模型文字胶囊；原站为 OpenAI、Claude、Gemini、DeepSeek、Qwen、Llama。每项小描边、12px、水平居中，hover 弱蓝强调。
- **02 安全可靠**：居中 64px 圆角方框，翡翠绿 5% 背景／20% 边框，28px 细线盾牌；右上 16px 绿色成功圆点内白勾。
- **03 全球覆盖**：三行数字节点，24px 圆形＋细横线＋右侧短标签；中间节点为蓝强调。标签为负载均衡、速率限制、成本跟踪；本次首页没有大型地球插画。
- **04 开发者友好**：API／SDK／CLI／Docs 四枚 32px 重叠圆片，2px 底色描边，9px 小字；旁边是 14px 代码图标与 12px 协议说明。

### 7. 四项辅助能力

主功能网格下方 48px，手机两列、md 起四列，gap 32 / 48px。内容居中，无大卡片背景。

每项由 48px 的小图标容器（12px 圆角、弱描边、muted 30%）＋14px/600 标题＋12px 两行说明组成，图标20px、线宽1.5。原站主题依次为高性能、透明计费、团队协作、开源项目。

### 8. 三步流程

顶部细分隔线，区块上下96 /128px。居中的小标签和标题，之后留64 /80px。手机单列、md 起三列，间距32 /48px。

每步：64px 圆角方形图标框（16px 圆角、图标24px、弱边框、muted30%）→右上方偏移8px的24px序号实心圆→下隔24px的16px/600标题→14px说明，说明最大240px。原站为配置、连接、监控；没有贯穿三步的粗连接线。

### 9. 结尾行动区

居中内容最大672px；两行标题，末行蓝紫文字渐变；说明最大448px，距离标题20px；下隔32px放两枚按钮。再次局部铺设低强度蓝青光晕，配方弱于首屏，无网格。原站对未登录用户显示这一段；迁移时按目标产品的登录状态或业务需要决定。

### 10. 实际页脚与轻量反馈

本次站点使用自定义页脚：细上边线，最大1152px、左右24px、上下20px；内部 muted20% 的圆角16px横条，左右16–20px、上下16px，左侧版权，右侧开源归属；桌面中间竖线，手机纵排并改横线。不是多列站点地图式页脚。

如果目标项目需要多列页脚可自行适配，不把原站未显示的默认页脚当作本次观察结果。页面还挂载轻量 toast（提示消息）容器；它是瞬时反馈，不是固定展示的营销模块。对失败、空公告、无时间线等状态使用现有产品的诚实状态。

## 动效参数与可访问性

| 行为 | 基准 |
|---|---|
| 淡入上移 | opacity 0→1、Y 24px→0；600ms；cubic-bezier(.16,1,.3,1) |
| 淡入微缩放 | scale(.95)→1；600ms；相同曲线 |
| 首屏错峰 | 胶囊0ms、标题60ms、说明120ms、按钮180ms、应用240ms、演示320ms |
| 下方入场 | IntersectionObserver，threshold .15，rootMargin `0px 0px -40px 0px`，触发一次 |
| 卡片错峰 | 100ms 递增；流程150ms递增 |
| 悬停色彩 | 200–300ms；不做强光扫射或夸张浮起 |
| 减少动态效果 | 停止自动协议轮播、直接显示最终计数、关闭脉冲和入场位移；保留手动切换 |

模板在参考之上增加了键盘导航、自动轮播暂停、无 JS 内容可见与弹层焦点管理。这些是可访问性适配，不是声称原站已逐项实现。优先用现有工程的成熟可访问组件承接。
